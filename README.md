## Research code

- [**soc-log-anomaly-dl**](https://github.com/aliradid/soc-log-anomaly-dl) — Reproduction of the ELSES 2023 SOC paper. BI-LSTM, GRU, and CNN are trained on a public substitute for the original private logs, and the paper's metrics are reported beside the new run. MIT.

- [**siem-ai**](https://github.com/aliradid/siem-ai) — Experiment scripts, figures, and a Docker streaming stack for the manuscript *OpenSIEM-AI: A Reproducible Open-Source Reference Architecture for ML-Driven SIEM and Automated SOAR Containment*. Apache-2.0.

- [**proctoring-privacy**](https://github.com/aliradid/proctoring-privacy) — Experiment code for the manuscript *A Privacy-Preserving Multi-Modal Proctoring Framework Using Deep Learning for Secure Online Examinations* (YOLOv8, MediaPipe, and Whisper). MIT.

## Software

- [**citation-needed**](https://github.com/aliradid/citation-needed) — Agent skill that checks factual claims in a draft against live sources and returns an evidence ledger. Installs on Claude Code, Codex, Cursor, Gemini CLI, OpenCode, and others. MIT.

- [**when-in-rome**](https://github.com/aliradid/when-in-rome) — Agent skill and git hook that makes commit messages, branch names, and pull requests follow the repository's own history. MIT.

- [**jarvis-macos**](https://github.com/aliradid/jarvis-macos) — Portfolio edition of a native macOS workspace written in SwiftUI. The demo builds and runs offline. Subscription and expense screenshots are captures of the personal app and are labeled as such; the rest of the demo data is fictional. All rights reserved.
